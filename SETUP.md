# Setup & Configuration

This repository (`ssambit635-svg/Ssambit635-svg`) is your special GitHub profile repository. Its `README.md` is what automatically displays on your public GitHub profile (`https://github.com/ssambit635-svg`).

---

## 1. What's Included

- **Dot-Matrix Portrait**: Generated using `scripts/dotify.py` from your portrait (`assets/portrait.jpg` -> `assets/portrait.svg`).
- **Typing Tagline Banner**: Highlighting your stack (Full Stack & Cloud, Python & TypeScript).
- **Social Badges**: LinkedIn, Email, Portfolio, X/Twitter, Hashnode, plus profile view counter.
- **Skill & Language Radars**: Interactive SVG spider charts generated by `scripts/radar.py`.
- **Contribution Calendar & Snake**: 3D Isometric activity map and animated Snake eating the commit graph.
- **Self-Hosted Metrics Cards**: Generated by `scripts/cards.py` to prevent third-party uptime outages.
- **Selected Work**: Interactive 2x2 grid of your featured projects (`Aws-dashboard-frontend`, `Weather-sense`, `Civic-report`, `Shadow-quest`).

## 2. GitHub Actions Setup (One-Time)

### A. Enable Read and Write Permissions for Actions
1. Go to your repo on GitHub: **Settings** → **Actions** → **General**.
2. Scroll to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Check **Allow GitHub Actions to approve pull requests** and click **Save**.

### B. Add `METRICS_TOKEN` (for 3D Calendar and Advanced Stats)
1. Go to [https://github.com/settings/tokens](https://github.com/settings/tokens) → **Generate new token (classic)**.
2. Note: Name it `METRICS_TOKEN`.
3. Scopes: Check **`read:user`** (and optionally **`repo`**).
4. Generate and copy the token.
5. In your repo: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
6. Name: **`METRICS_TOKEN`**, Secret: Paste the token value.

### C. Run the Workflows
In the **Actions** tab on GitHub:
- **Metrics**: Generates `assets/metrics.*.svg` (runs every 6h).
- **Snake**: Generates the animated snake onto the `output` branch (runs every 12h).
- **Charts and cards**: Automatically refreshes the radars and cards from live repo data.

## 3. Local Customization & Artwork Commands

All scripts are in the `scripts/` folder and can be run locally anytime:

### Regenerating the Portrait
```bash
# Color dot-matrix with reveal animation (current)
python scripts/dotify.py assets/portrait.jpg -o assets/portrait --square --focus 0.55,0.40 --cols 90 --equalize --detail 0.5 --color --reveal

# Green hacker monochrome version
python scripts/dotify.py assets/portrait.jpg -o assets/portrait --square --focus 0.55,0.40 --cols 90 --equalize --detail 0.5 --animate

# Binary mode (0s and 1s)
python scripts/dotify.py assets/portrait.jpg -o assets/portrait --mode binary --square --focus 0.55,0.40 --cols 64 --equalize --detail 0.5
```

### Refreshing Skill & Language Radars
```bash
# Update skills from assets/skills.json
python scripts/radar.py --data assets/skills.json -o assets/radar

# Update language radar from your public GitHub repos
python scripts/radar.py --github ssambit635-svg -o assets/radar-langs --limit 7 --values --curve 0.4
```

### Updating Project & Stats Cards
```bash
# Update cards from assets/projects.json
python scripts/cards.py --user ssambit635-svg --projects assets/projects.json --out assets
```

### Local Preview
Open `preview.html` in your browser to view all dark and light mode assets side-by-side!
